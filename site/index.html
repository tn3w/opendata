Open network data

Three datasets, built on one home server and free to use for any purpose under CC0 1.0, without registration or keys. Every file allows cross-origin requests. Run by tn3w. Source code and full downloads: github.com/tn3w/opendata.

Reverse DNS for IPv4

The PTR records of the IPv4 address space, so a hostname can be found for an address without asking a DNS server. A full pass takes several days and starts again every 30 days. /rdns/stats.json shows how far the current pass is; until the first pass ends, addresses not yet reached return no names.

GET /rdns/lookup/8.8.8.8          {"ip":"8.8.8.8","ptr":["dns.google"]}
GET /rdns/v4/8/8.tsv.zst          one /16 (here 8.8.0.0/16)
GET /rdns/v4/files.txt            every /16 file that exists, in address order
GET /rdns/v4/all.tsv.xz           the whole database of the last finished pass

The whole database is one xz file, written when a pass ends and about half the size of all /16 files together. The same file is mirrored on GitHub, which is faster:

curl -sfL https://github.com/tn3w/opendata/releases/download/data/rdns-v4.tsv.xz \
  | xz -d > rdns-v4.tsv

The /16 files are zstd-compressed text with one line per record: address<TAB>hostname, sorted by address, hostnames in lower case without the trailing dot. Bytes outside printable ASCII are written as \DDD. An address with several PTR records has several lines. A missing file means the range has no records.

How it is gathered: the scanner walks in-addr.arpa from the top. A name that does not exist (NXDOMAIN) for a /8, /16 or /24 rules out everything below it with one question, so most of the address space is never asked about one address at a time. Questions go to public resolvers over UDP, pipelined TCP and DNS over TLS, with a congestion window per connection so that no resolver is asked faster than it answers.

Abuse IP list

Addresses that attacked this server's websites: requests for paths only attack tools ask for (such as /.env, /wp-login.php or /.git/config, none of which exist here), injection attempts in the query string, known scanner tools and unusual request methods.

GET /abuse/ips.txt                one address per line
GET /abuse/ips.json               {"203.0.113.6":{"first_seen":…,"last_seen":…,
                                   "requests":3,"categories":["php","wordpress"]}}

Categories: secrets, wordpress, php, admin, exploit, traversal, injection, scanner, method.

Crawler IP list

Addresses of every client whose User-Agent is not a browser's, as classified by iscrawl, listed from the first request. This covers search engines and AI crawlers as well as command-line tools, libraries and link previews. It is a list of automated clients, not of bad ones.

GET /crawlers/ips.txt             one address per line
GET /crawlers/ips.json            {"203.0.113.7":{"first_seen":…,"last_seen":…,
                                   "requests":42,"robots_txt":true,
                                   "user_agents":["…"],"tags":["search-engine"],
                                   "ptr":["…"],"verified":true}}

tags come from Crawlerdex. ptr is the reverse DNS from the dataset above, looked up when the address is first listed and again whenever the list service restarts. verified is true when that hostname belongs to the operator the User-Agent names, false when it does not (someone borrowing the name), and null when it cannot be checked.

Shared rules for both lists

  • Times are Unix timestamps rounded down to the start of the day (UTC).
  • IPv6 clients are listed as their /64 network.
  • Entries are never removed.
  • The lists are rebuilt every five minutes and uploaded hourly to the GitHub release (abuse.txt, abuse.json, crawlers.txt, crawlers.json).

Privacy

The web server keeps no access log on disk. Requests are classified in memory, and only the entries published above are ever written down. A visitor with an ordinary browser who attacks nothing leaves nothing behind.

  • Requests that a web page caused in a visitor's browser (anything a browser marks as coming from another site) are ignored for the abuse list, so nobody can be put on it by being sent a link.
